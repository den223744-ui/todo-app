## Реализовано

- Список подключён в `App`; фильтрация по списку/тегу/поиску из URL.
- `domain/taskGroups.ts` компонует существующие фильтры и поиск. Сегодня:
  просроченные отдельно сверху; предстоящие: по дням. Пустые группы скрыты.
- TaskRow: чекбокс, название, локальная дата/время, приоритет, теги.
  Просроченные даты выделены, выполненные названия зачёркнуты.
- Выполнение/возврат через существующий useUpdateTask: оптимистично, с откатом.
  Пока идёт любая мутация задач, чекбоксы отключены, чтобы не создавать
  конфликтующие записи до ответа сервера. Ссылки остаются доступны.
- Открытие задачи пишет task в URL, сохраняет список/тег/поиск; выделяется строка.
  Ctrl/Cmd/Shift/Alt и средняя кнопка сохраняют поведение настоящих ссылок.
  Панель деталей появится в пункте 5.
- Пустые состояния для каждого списка/тега/поиска, статичные скелетоны.
  Ошибка первой загрузки с повтором; при ошибке фонового запроса кеш остаётся виден.
  Ошибка выполнения пока показана внутри списка, глобальные тосты — пункт 6.
- Сохранены токены, Inter, адаптив и системная тема. Новых зависимостей нет.
