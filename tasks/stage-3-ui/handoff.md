## Пункт 4: быстрый ввод

- App → QuickAdd. Нативное поле и aria-hidden слой точной подсветки диапазонов
  из существующего parseQuickAdd. Текст не интерпретируется как HTML.
  Подсветка синхронизируется с прокруткой, изменением ширины и загрузкой шрифта.
  На мобильном шрифт поля 16px; в forced-colors читается нативный текст без слоя.
- `domain/quickAddInput.ts`: API TaskCreate из парсера и текущего View.
  Сегодня подставляется только без даты; явная дата и правило парсера для времени
  без даты сохраняются. Текущий тег добавляется к явным без дублей.
- Пустое название/ввод только из токенов и название >500 Unicode code points
  не отправляются. Длина проверяется после удаления токенов.
- Enter и кнопка вызывают useCreateTask, задача появляется оптимистично.
  Поле очищается после успеха. При ошибке — откат и сохранение полного текста.
  Во время запроса поле readOnly; синхронный ref блокирует повторные сабмиты.
- IME-композиция не отправляет задачу по Enter. После успеха фокус возвращается
  в поле, если пользователь ещё внутри формы. Ввод переживает смену представления;
  контекст и время пересчитываются при отправке, в том числе после полуночи.
- Ошибки пока показаны внутри формы/списка. Общие тосты — пункт 6.
- Новых зависимостей нет; сохранены токены, Inter и системная тема.

## Пункт 3: список задач

- Список подключён в `App`; фильтрация по списку/тегу/поиску из URL.
- `domain/taskGroups.ts` компонует существующие фильтры и поиск. Сегодня:
  просроченные отдельно сверху; предстоящие: по дням. Пустые группы скрыты.
- TaskRow: чекбокс, название, локальная дата/время, приоритет, теги.
  Просроченные даты выделены, выполненные названия зачёркнуты.
- Выполнение/возврат через существующий useUpdateTask: оптимистично, с откатом.
  Пока идёт любая мутация задач, чекбоксы отключены, чтобы не создавать
  конфликтующие записи до ответа сервера. Ссылки остаются доступны.
- Открытие задачи пишет task в URL, сохраняет список/тег/поиск; выделяется строка.
  Ctrl/Cmd/Shift/Alt и средняя кнопка сохраняют поведение настоящих ссылок.
  Панель деталей появится в пункте 5.
- Пустые состояния для каждого списка/тега/поиска, статичные скелетоны.
  Ошибка первой загрузки с повтором; при ошибке фонового запроса кеш остаётся виден.
  Ошибка выполнения пока показана внутри списка, глобальные тосты — пункт 6.
- Сохранены токены, Inter, адаптив и системная тема. Новых зависимостей нет.
